# Student Record Management System Using C

A Student Record Management System developed using the **C programming language** and **Singly Linked List** data structure. This project allows users to efficiently manage student records through a simple menu-driven interface.

## Features

- Add new student records
- Display all student records
- Search for a student record
- Update existing student information
- Delete a specific student record
- Delete all student records
- Dynamic memory allocation using linked lists
- Menu-driven interface

## Technologies Used

- **Programming Language:** C
- **Data Structure:** Singly Linked List
- **Concepts Used:**
  - Structures
  - Pointers
  - Dynamic Memory Allocation
  - Functions
  - Linked List Operations
  - File Handling

## Project Structure

- `main.c` – Main program and menu
- `header.h` – Structure definitions and function declarations
- `add_record.c` – Adds new student records
- `delete_record.c` – Deletes a student record
- `deleteall_record.c` – Deletes all student records
- `load_record.c` – Loads student records
- `Makefile` – Used to compile the project

## Objective

The main objective of this project is to demonstrate the practical implementation of **C programming and data structures**, particularly linked lists, in a real-world student record management application.
